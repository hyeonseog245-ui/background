# 🎨 백그라운드 생성기 (CSS Gradient Generator)

컬러 피커(Color Picker)를 이용해 원하는 두 가지 색상을 선택하면, 실시간으로 배경 색상이 선형 그라데이션(Linear Gradient)으로 변경되고 해당 CSS 코드를 생성해 주는 웹 애플리케이션입니다.

---

## 📌 주요 기능 (Features)

- **실시간 그라데이션 적용**: 색상을 선택할 때마다 웹 페이지 배경(`body`)의 그라데이션 효과가 즉시 업데이트됩니다.
- **CSS 코드 추출**: 현재 변경된 배경의 CSS 선형 그라데이션 코드(`linear-gradient(...)`)를 화면에 텍스트로 표시해 쉽게 복사할 수 있습니다.
- **직관적인 UI**: HTML5의 Color Input을 사용하여 손쉽게 원하는 색상을 선택할 수 있습니다.

---
